# Reloj Universal

Aplicación para buscar y mostrar la hora actual de diferentes países, estados y ciudades del mundo en tiempo real.

## Instalación

```bash
npm install
npm run dev
```

## Características

- Búsqueda de ciudades, países y zonas horarias
- Visualización de relojes en tiempo real
- Información de offset UTC
- Diseño responsivo con modo oscuro
